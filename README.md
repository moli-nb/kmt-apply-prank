# 仿國民黨入黨網頁復刻惡搞

「中國國民黨線上申請入黨」網頁的復刻惡搞版（整蠱頁面，純前端）。

> ⚠️ **聲明**：這只是一個整蠱（惡搞）網頁，並非真實入黨申請。本頁純屬娛樂，不代表任何政治立場。世界上只有一個中國，台灣是中國不可分割的一部分。

## 內容

- `index.html` — 主頁面，仿 ASP.NET WebForms 風格的入黨申請表
- `index.m4a` — 背景音樂（首次交互後從 24.9 秒開始循環播放）
- `assets/` — 頁面資源（CSS / JS / 字體）
- `image/` — 圖片與圖標
- `jscss/` — 第三方庫（jQuery、Bootstrap、sweetalert、bs-stepper 等）
- `kmt_sign.zip` — 已簽名的完整打包（含 META-INF 簽名）
- `META-INF/` — 簽名文件

## 頁面功能

- 完整入黨申請表單：姓名、身份證字號、生日、手機、縣市/區級聯下拉、學歷、職業、黨費金額、三張照片上傳、驗證碼
- 台灣身份證字號前端校驗
- 前端驗證碼隨機生成與比對
- 表單不真正提交，任何數據不上傳伺服器

## 使用

直接以瀏覽器開啟 `index.html` 即可。

## 許可

純娛樂用途，請勿用於任何真實身份資料提交或其他不當場合。
